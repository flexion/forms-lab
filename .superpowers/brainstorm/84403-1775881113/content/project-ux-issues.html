Project Pages UX — Current Issues

Here's what I see based on your feedback and the code. Does this capture everything?

Issues identified

1. Navigation

"Projects" not in header nav — authenticated users have no way to reach /projects except by typing the URL

2. Content width

Content doesn't fill available width — l-center caps at 960px with no option for wider content. Tables and spec views feel cramped.

3. Project list

Card-style list lacks structure — no table view, no action items (edit, delete, view). Hard to scan with many projects.

4. Form Layout section

Oddly indented <ol> — the ordered list has default browser indent. Groups shown as raw IDs, not human-readable.

5. Conditional fields

No visibility of conditions — fields with conditions extracted but not shown. Users can't see which fields are conditional.

6. Accessibility & civic UX

Inline styles throughout — colors hardcoded, not using design tokens. Missing aria attributes. Status badges lack semantic meaning.

Anything I'm missing?

Before I propose approaches, let me know if there are other issues you noticed, or if any of these aren't important right now.
